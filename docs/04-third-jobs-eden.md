# 04｜設定三轉與伊甸園

狀態：玩法測試

這是你在本專案提出的新目標。舊分享對話以轉生二轉的懷舊模式為主，沒有完成三轉或伊甸園設定。

- 備份目前可啟動的 Server 與資料庫，確認 rAthena commit、renewal.hpp、defines_pre.hpp 及 Client 日期。

- 決定 Renewal 模式與職業/等級上限。原有 #define PRERE 需要重新檢視；切換模式前先確認資料庫與腳本差異，不只改一行便宣告完成。

- 核對目前 rAthena 版本的三轉職業、轉職 NPC 與等級資料；將你要的三轉上限記錄下來。尚未選定 150 / 175 等上限。

- 核對伊甸園 NPC 腳本是否存在且已被載入；確認入口、裝備與任務實際運作。此文件不臆造腳本路徑或匯入設定。

- 讓 Client 顯示三轉角色、技能與伊甸園相關道具；保留相同 PACKETVER 配對。

- 以測試帳號驗證轉職、技能、任務與獎勵，再把成功設定補回 01 的進度總覽。
本次僅整理與建好這個分類，沒有變更 Server 模式、加 NPC 或設定職業。
